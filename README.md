# 凱旋國中 115 學年度數位學生手冊｜GitHub Pages 版

## 上傳方式
請將本資料夾「裡面的檔案」直接上傳到 GitHub Repository 的最外層（根目錄），不要再多包一層資料夾。

根目錄應看到：
- index.html
- student-handbook.pdf
- schedule.pdf
- .nojekyll

## 重要
1. 首頁檔名必須是 `index.html`。
2. GitHub Pages 建議設定：Settings → Pages → Deploy from a branch → main → /(root)。
3. 網站中的章節按鈕已使用 `student-handbook.pdf#page=頁碼`，會直接開啟學生手冊對應頁。
4. 作息表按鈕使用 `schedule.pdf`。
